# duration-iso-core

Durações ISO 8601 em unidades inequívocas (semanas/dias/horas), com
rejeição explícita de anos/meses ambíguos. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes, node:test, sem dependências
npm run demo
```

No máximo 366 dias; `P1Y` falha em vez de adivinhar. MIT — veja `LICENSE`.
